# Goal Portal

Goal Portal is a role-based goal management platform that helps employees create and submit goals, and helps managers review, approve, or return them through a clear workflow.

## What Goal Portal does

Goal Portal simplifies the goal-setting process inside an organization.

Instead of managing goals through scattered spreadsheets, messages, and follow-ups, the platform keeps everything in one place so users can create goals, track their status, and complete reviews more smoothly.

## Who should use it

### Employees
Use Goal Portal to:
- Create goals
- Save goals as drafts
- Edit goals before submission
- Submit all draft goals when ready
- Track whether goals are submitted, approved, or returned

### Managers
Use Goal Portal to:
- Review goals submitted by employees
- Approve goals that are ready
- Return goals that need changes
- Track the status of team submissions from one place

## Main features

- Secure sign-in with Microsoft
- Separate employee and manager experiences
- Draft-based goal creation workflow
- Bulk submission of draft goals
- Goal review and approval flow
- Clear status tracking across the goal lifecycle
- Dashboard-based visibility for both roles

## How the workflow works

1. Sign in with your Microsoft account.
2. Access the dashboard assigned to your role.
3. If you are an employee, create goals and save them as drafts.
4. Submit your draft goals when they are complete.
5. If you are a manager, review submitted goals from your dashboard.
6. Approve goals or return them for changes.
7. Track updated goal statuses in the platform.

## Goal statuses

Goal Portal uses clear status stages so users always know where a goal stands.

- **Draft** — the goal has been created but not yet submitted.
- **Submitted** — the goal has been sent for manager review.
- **Approved** — the goal has been reviewed and accepted.
- **Returned** — the goal needs changes before approval.

## Why it is useful

Goal Portal helps reduce confusion in review-based workflows.

It improves visibility for employees, gives managers a structured review process, and makes the full goal lifecycle easier to understand at a glance.

## User guide

### For employees

1. Sign in to the platform.
2. Open your dashboard.
3. Add one or more goals.
4. Save unfinished goals as drafts.
5. Review your drafts.
6. Submit all draft goals when ready.
7. Check the status of submitted goals regularly.

### For managers

1. Sign in to the platform.
2. Open the manager dashboard.
3. Review employee submissions.
4. Approve goals that meet expectations.
5. Return goals that need revision.
6. Monitor which goals are pending, approved, or sent back.

## Best practices

- Write clear and specific goals before submission.
- Review draft goals carefully before submitting all of them.
- Managers should return goals with actionable feedback.
- Check the dashboard regularly for updated statuses.

## Access and sign-in

Goal Portal uses Microsoft sign-in for secure access.

After login, the application opens the correct experience based on the user's role.

## Known limitations

- In some deployed environments, status updates may appear after a refresh in certain cases.
- Email-related notifications may depend on deployment mail service availability.

## Product summary

Goal Portal is designed to make employee-manager goal workflows cleaner, more transparent, and easier to manage from submission through approval.
